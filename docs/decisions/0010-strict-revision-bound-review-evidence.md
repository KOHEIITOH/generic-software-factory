# ADR-0010: レビューは同じ対象版・試行へ固定し、未知や欠落を成功にしない

- 状態: 採用（マージ後）。R10a。

参考資料の実装/レビュー分離と指摘の再集計を採用する。ただし未知severityの破棄や、
コメントのマーカーだけでproducerを信用する方式は採らない。

信頼されたcontrollerが実装者とreviewerの独立性を確認し、版と変更pathを不変の計画へ登録する。
応答は閉じたschemaで検査し、must-fixをfindingsから再計算する。不正/未知の応答は取込みを拒否し、
失敗や部分レビューは不合格として保持する。次の試行ではレビューもやり直す。

初期は指摘件数・応答hash・coverage flagsのみ保存する。詳細Artifact/AI呼出し/認証は後続。
evidence_completeと提出権限を分離し、実行/成果物の信頼経路が揃うまでdelivery適格はfalseのまま。
